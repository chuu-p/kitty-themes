# anime themes for the kitty terminal

![](./screenshots/misa.conf.png)

## installation

```
cd ~/git
git clone https://github.com/chuu-p/kitty-themes
```
the themes have to live at `~/git/kitty-themes` for the background images to work out of the box.

to change it, change:
`background_image               ~/git/kitty-themes/images/misa-0.02.png`
to your preferred path.
